OURO NEGRO RODAS — PUBLICAÇÃO

1. Abra https://dash.cloudflare.com/ e entre em Workers & Pages.
2. Crie um projeto Pages com upload direto (Direct Upload).
3. Envie a pasta ouro-negro-rodas-publicar (ou o ZIP descompactado).
4. Abra o endereço HTTPS gerado pelo Cloudflare Pages.
5. No Chrome Android, use menu ⋮ > Adicionar à tela inicial / Instalar app.
6. Para atualizar todos: publique os arquivos novos no MESMO projeto Pages.

IMPORTANTE:
- Cada aparelho mantém suas próprias rodas, favoritos e músicas importadas no armazenamento do navegador para este endereço.
- Não altere o domínio/URL do projeto; isso pode fazer os dados parecerem perdidos.
- Apagar dados do site, desinstalar em alguns navegadores ou trocar de aparelho pode apagar os áudios locais.
- Exportar backup salva dados da roda, não os arquivos de áudio. Mantenha os MP3/M4A originais.
- O site NÃO inclui 41 gravações de terceiros: cada usuário pode importá-las do próprio aparelho. Para distribuir uma biblioteca padrão a todos, é preciso ter direito de distribuição dos áudios e hospedá-los separadamente.
- A publicação requer acesso à conta Cloudflare do responsável. Este pacote não foi publicado automaticamente.
- Funciona offline após o primeiro carregamento para recursos do app em cache, mas áudio importado depende do armazenamento local estar disponível.
